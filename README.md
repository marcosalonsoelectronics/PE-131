This video shows how to integrate two power inductors in a single core. First, the magnetic integrated structure is introduced and explained. The reluctance-based model of the structure is presented. From this model, the video shows how to calculate the self-inductance of each winding, the mutual inductance, and the coupling coefficient. An electrical model is also shown. Finally, a magneto-electric model is implemented in Qspice. An example and simulation results are also presented.
